# Changelog

## Unreleased — 0.3.0

- Rust/WASM document model, versioned edits, history and persistent rich-text decorations.
- WebGPU rendering, Worker-based layout, grapheme navigation and visual RTL/BiDi caret handling.
- Standalone browser component with Shadow DOM, TypeScript entries, instance disposal and local packaging.
- Asynchronous highlight rebasing, themes and an optional WebSocket LSP adapter.
- Hover widgets, definition navigation, logical-line and word selection, configurable indentation and edit callbacks.
- Large-text fixtures, visible-window ASCII layout and in-editor performance metrics.
- Diagnostic underlines, severity gutter marks, composed hover messages and F8 navigation with version checks.
- Atomic scene and glyph-atlas commits that retain complete visible content during asynchronous layout.
- Configurable keyboard commands, logical-line clipboard operations, Worker-prepared line transforms and middle-click definition navigation.

Current compatibility and performance boundaries are documented in [performance and limitations](docs/performance.md).
