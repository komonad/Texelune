一个组件，两个独立实例。

同页共享 WASM 与模块，每个实例拥有独立文档、布局 Worker、渲染资源和主题。

import { createEditor } from 'texelune-editor';
const editor = await createEditor(container, {
  value: 'fn main() {}', theme: 'paper', filename: 'main.rs'
});
editor.root.host.addEventListener('change', ({ detail }) => console.log(detail));
editor.setTheme('dusk');
// Release workers, observers, event handlers and GPU resources.
editor.destroy();
